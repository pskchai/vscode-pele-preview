## [1.0.0] - 2026-10-25

First release of Pele Preview, based on Mermaid Chart's VS Code Mermaid Preview.

### Added

- Local diagram and Markdown previews with Pele.
- Preview Diagram button in the editor toolbar for Mermaid files.

### Removed

- Minor features from the [original extension](https://github.com/Mermaid-Chart/vscode-mermaid-preview).
  - Primary sidebar and its settings and feedback pages.
  - Usage analytics and related network code.
  - Feature-moved notifications and extension promotion.
  - Connect Diagram, Sync Diagram, Link Diagram, and their command handlers.
  - Original extension account checks, unused assets, and obsolete build files.
