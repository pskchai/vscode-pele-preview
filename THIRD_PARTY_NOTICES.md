## Provider icon assets

The extension also includes SVGs downloaded directly from the cloud providers. These assets retain the providers' terms. They are not covered by this project's MIT license. The exact archive URLs and SHA-256 checksums are recorded in [sources.json](assets/cloud-icons/sources.json).

- AWS architecture icons: Amazon Web Services. AWS permits customers and partners to use the assets to create architecture diagrams and related materials. See the [AWS architecture icon page](https://aws.amazon.com/architecture/icons/) for terms.
- Azure architecture icons: Microsoft. Microsoft permits copying, distribution, and display for architectural diagrams, training materials, and documentation. All other rights are reserved. See the [Azure icon terms](https://learn.microsoft.com/en-us/azure/architecture/icons/#icon-terms).
- Google Cloud product and category icons, including legacy console icons: Google LLC. See the [official Google Cloud icon library](https://cloud.google.com/icons) and [Google brand permissions](https://about.google/brand-resource-center/).

Sizing and color attributes are added to the SVGs. CSS class styles are put on each element. Icon shapes are unchanged. Brand and service marks belong to their respective owners.
